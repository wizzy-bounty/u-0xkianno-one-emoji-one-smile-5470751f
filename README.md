# One Emoji, One Smile

Entry for the [One Emoji, One Smile](https://make.fun/c/u-0xkianno-one-emoji-one-smile-5470751f) competition on make.fun.

## The entry

Exactly one emoji: 🌞 (U+1F31E, SUN WITH FACE).

Sunshine is the plainest symbol of warmth there is, and the smiling face turns it into a greeting — a stranger reading it feels wished well, not addressed. It is warm at first glance, universal across every age and culture, a deliberate pick rather than the first smiley that comes to mind, and it carries no intimacy, sarcasm, or flirtation from someone unknown.

## How it works

`main.py` (Python standard library only, deterministic, no network) writes that single emoji — and nothing else — to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`).

```sh
python3 main.py
```
